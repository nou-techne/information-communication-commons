# Journal — commons.id

Sprint journal for the Information & Communications Commons.

## Structure

- `CHANGELOG.md` — versioned release notes (semantic versioning)
- `VERSION` — current version number
- `YYYY-MM-DD.md` — daily sprint journal entries

## Sprint Journal Format

Each entry includes:
- **Sprint number** and title
- **TIO role** (primary role embodied for quality criteria)
- **Layer** (which of the 7 progressive design patterns)
- **Block** (Reliability / Experience / Infrastructure / Depth)
- **Artifact produced** (what was built, changed, or validated)
- **Key decisions** and observations
- **Status** (complete / in-progress / blocked)

## Versioning

- **0.x.y** — Pre-ETHBoulder development
- **1.0.0** — ETHBoulder launch (Feb 13, 2026)
- Patch (0.9.x): bug fixes, extraction tuning
- Minor (0.x.0): new features, UI enhancements
- Major: breaking changes to schema or API

## Cadence

Journal entries every 4 sprints (~1 hour at 15-minute heartbeat).
