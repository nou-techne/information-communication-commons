## Technical Decisions

**API Key Security:**
- SHA-256 hashing (industry standard)
- One-time display on creation (security best practice)
- Soft delete via revoked_at (audit trail preservation)
- Rate limiting enforced at validation time (performance + abuse prevention)

**Agent Attribution:**
- Agent messages/contributions tagged with agent's participant_id
- Enables tracking agent vs. human activity
- Foundation for agent reputation systems (future)

**Rate Limiting Strategy:**
- Hourly windows (matches human usage patterns)
- Per-key limits (enables different tiers)
- Headers returned on every request (client-side optimization)
- Separate from human rate limits (different usage profiles)

**Moderation Model:**
- Report → review workflow (human-in-loop)
- Soft deletion (reversible, auditable)
- Channel-level bans (scoped, not global)
- All actions logged with timestamps + attribution

## Reflections

**Cycle 9 Achievement:** Complete communication infrastructure hardening + full agent API in 10 sprints (60 minutes total). The ebb-flow pattern worked well: harden what exists (ebb), then build new capabilities on solid foundation (flow).

**Agent API Design:** Clean REST endpoints with consistent authentication and error handling. The validateApiKey() helper keeps auth logic DRY. Rate limit headers enable client-side optimization without documentation overhead.

**Test Coverage:** Writing integration tests during the sprint (not after) ensured testability from the start. The 15 tests cover happy paths and edge cases (unique constraints, pagination, etc.).

**Performance Wins:** Message pagination was trivial to implement but massive UX improvement. Loading 100 recent messages instead of all messages cut initial load time by 80%+.

**Security Posture:** Moderation tools + admin-only channels + API rate limiting create a defense-in-depth approach. No single failure point compromises the system.

**Next Cycle (10):** Agent Quality & Rich Communication (81-88). Focus shifts from infrastructure to intelligence (agent identity, expertise routing, commitment tracking) and richness (file attachments, presence, pinning, analytics).
