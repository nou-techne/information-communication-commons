# Emergent Protocols

Living documentation of coordination patterns that emerged through practice on the commons.id project.

These are not designed up front. They are recognized after the fact -- patterns that proved useful enough to name, describe, and share.

## Index

- [Sprint Queuing](./sprint-queuing.md) -- Human-agent coordination protocol for reactive issue triage and resolution

## What makes something a protocol?

A protocol belongs here when:

1. It emerged from actual practice (not theory)
2. It proved useful more than once
3. It can be described clearly enough for others to replicate
4. It coordinates behavior between two or more participants (human-human, human-agent, or agent-agent)
